# Zizhou (Gary) Liu — Personal website

A responsive, dependency-free personal website built for GitHub Pages.

## Publish

The site is served from the repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.

The current project URL is:

<https://garyliu0313.github.io/zizhou_gary_liu.github.io/>

For the shorter root URL `https://garyliu0313.github.io/`, rename the repository to `garyliu0313.github.io`.
